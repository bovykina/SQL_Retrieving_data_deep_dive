# Глубокое погружение в JOINs в SQL

## Описание
В учебном проекте была углублённая работа с SQL и реляционными базами данных. В ходе выполнения заданий изучила различные типы соединений таблиц, обработку отсутствующих данных, генерацию дат, использование CTE и фильтрацию информации с помощью SQL-запросов. Практическая часть основана на базе данных пиццерий, клиентов, меню, посещений и заказов.

## Полученные навыки
- Работа с JOIN - объединение таблиц с использованием различных типов соединений
- Обработка пропущенных данных - поиск отсутствующих записей и работа с NULL
- Использование CTE - структурирование запросов с помощью общих табличных выражений
- Фильтрация данных - отбор записей по датам, возрасту, полу, адресу и другим условиям
- Составление аналитических запросов - поиск связей между клиентами, заказами, пиццами и пиццериями

## Этапы проекта
1. Поиск несвязанных записей, определение пиццерий, которые никто не посещал
2. Анализ пропусков в данных, поиск отсутствующих дат и обработка неполных результатов соединения
3. Структурирование SQL-запросов, применение CTE для организации логики выборки
4. Анализ меню и заказов, поиск популярных видов пиццы, подходящих пиццерий и клиентов с заданными предпочтениями
5. Объединение данных для анализа, сопоставление информации о людях, посещениях, заказах и адресах

## Заключение
В проекте закреплены навыки объединения таблиц и работы с реляционными данными в PostgreSQL. Практические задания помогли разобраться в обработке отсутствующих записей, использовании CTE и составлении запросов для анализа клиентов, посещений, меню и заказов.
